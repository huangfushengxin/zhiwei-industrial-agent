# 第三方素材来源说明

依据赛事通知第九条「使用既有代码、第三方组件、数据、图片、3D 资产及其他素材的，须如实说明来源和使用方式」，现说明如下。

## 一、运行底座与模型（赛事指定）

| 名称 | 版本 | 来源 | 许可 | 使用方式 |
|---|---|---|---|---|
| **Agnes Harness (AGH)** | 源码构建版（commit 见 `evidence/`） | https://github.com/AgnesAI-Labs/agnes-harness | Apache-2.0 | 作为智能体**运行与执行底座**；本项目**未修改 AGH 源码**，仅通过官方 MCP 与 Skill 机制接入自有工具 |
| **Agnes 模型** | `agnes-3.0-flash` | Agnes AI 官方 API（`https://api.agnes-ai.cn/v1`） | 依 Agnes AI 服务条款 | 作品中的**全部模型调用**（任务规划、工具选择、结论生成）。**未使用任何其他厂商、品牌或第三方模型** |

> 合规说明：AGH 内仅配置 1 个模型账号（`agnes-ai / agnes-3.0-flash`），密钥由团队自行申请并保管；
> **代码仓库中不含任何 API Key**。

## 二、开源组件

| 名称 | 版本 | 来源 | 许可 | 使用方式 |
|---|---|---|---|---|
| Model Context Protocol Python SDK (`mcp`) | 2.3.0 | PyPI / modelcontextprotocol | MIT | 将本项目自研的工业运维工具封装为 MCP 标准服务，供 AGH 调用 |
| Python 标准库 | 3.13 | 官方 | PSF | 全部算法实现（`statistics` / `csv` / `math` / `http.server` 等） |
| Node.js / pnpm | 24.x / 10.34.5 | 官方 | MIT | 运行与构建 AGH |

**本项目除上述组件外未引入其他第三方依赖**：Python 侧仅使用标准库 + MCP SDK，
无 numpy / pandas / scikit-learn 等库。

## 三、数据与素材

| 素材 | 来源 | 说明 |
|---|---|---|
| 工业传感器数据（`data/*.csv`、`data/test/*.csv`） | **团队自行程序化生成** | 依据离心泵机组（电机 + 联轴器 + 离心泵 + 轴承座）的物理量关系与故障机理建模生成，**非任何第三方数据集**；生成器见 `tools/generate_sensor_data.py`、`tools/make_boundary_case.py`、`tools/make_test_csvs.py` |
| 维修后复测数据（`data/repairs/*.csv`） | **团队程序化生成** | 由 `tools/simulate_repair.py` 按修复彻底度生成 |
| 故障知识库（特征指纹、维修工序、验收标准） | **团队原创** | 依据通用工业检修常识与公开的旋转机械故障机理整理，见 `tools/fault_library.py` |
| 图片 / 3D 资产 | **未使用** | 作品不含任何第三方图片或 3D 资产 |
| 字体 / 图标 | **未使用外部资源** | 演示页面使用系统字体与内联样式，无外部 CDN 依赖 |

## 四、代码原创性说明

| 目录 | 原创性 |
|---|---|
| `tools/`（工业工具链、检测/诊断/方案/维修/验证算法、验收脚本） | **100% 团队原创** |
| `agent/mcp/`（MCP 工具服务） | **100% 团队原创**（基于 MCP SDK 标准接口） |
| `app/`（演示网页 + 本地演示服务） | **100% 团队原创** |
| `data/`（全部数据） | **100% 程序化生成** |
| `evidence/`（执行记录、trace、验收报告） | **由 AGH 与本项目脚本自动产出** |
| AGH 源码 | **第三方（Apache-2.0）**，未修改，未包含在本作品原创部分内 |
